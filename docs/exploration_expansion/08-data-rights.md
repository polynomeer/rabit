# 데이터 소스·권리·개인정보 정책 제안

## Source matrix
| 데이터 | 후보 | 확인 사항 | 공개 전 gate |
|---|---|---|---|
| 릴리스 메타데이터/아티스트 | 기존 Rabit catalog + MusicBrainz 등 | 저작자표시·재사용 조건·정합성, release group/edition 차이 | 공급자 조건 확인 |
| 음악 크레딧/관계 | 기존 `catalog` | provenance, API 계약, 제3자 이용 | 기존 DIG OQ-DIG-06 |
| Billboard 등 역사 차트 | Billboard/공식 차트/라이선스 제공업체 | 복제·재배포·브랜드·차트 아카이브 허가, 보존/캐싱 범위 | **Legal + Contract 필수** |
| 지리·국가 경계 | GeoNames/OSM/기타 지도 SDK | attribution, 타일 API/캐싱/상업 사용 | 소스별 검토 |
| 역사적 리뷰/인터뷰 | 출처 링크/라이선스 받은 본문 | 저작권·발행일, 직접 인용 한도 | 편집 검증 |
| 오디오/앨범 이미지 | Rabit 권리 허가 카탈로그 | preview/stream/cover 권한, 사용 지역 | 기존 rights grant |
| 사용자의 청취/저장 | Rabit 제1자 자료 | 수집 목적/동의/보존/삭제/export | Privacy review |
| 외부 Spotify/Apple 청취 기록 | 공급자 정책이 허용하는 범위 | OAuth scopes, export 가능성, 접근 제한 | 공급자별 검증 |

## 절대 혼동 금지
- **Atlas 지역**: 사용자가 탐색하는 음악의 지역·차트 범위.
- **사용자의 실제 위치**: 민감한 개인정보일 수 있으며 기본 미수집.
- **license_country**: 실제 콘텐츠 접근 권리 판정에 사용되는 계정/계약 지역. 지도 선택으로 변경 금지.
- **차트 시점**: 집계 기간 및 발표 시점. 앨범 발매일과 다름.
- **시대의 인기 vs 현재 인기**: DIG Deep Cut은 Rabit 청취 기준, 역사적 인기의 증거로 사용 금지.
- **verified vs inferred**: `MusicRelation`의 근거 모델 유지.

## 안전/프라이버시
- 지역별 참여자 차트: 기존 `music-atlas.md`의 지역 기여 동의·threshold·비식별 집계가 선행; 과거 공식 차트와 DB를 공유하거나 라벨을 혼동하지 않음.
- 개인 청취 시간축 및 좋아요: 계정별 분리, 목적별 동의, 삭제/내보내기; 자료 없는 기간을 '음악을 듣지 않음'으로 추정하지 않음.
- 퀘스트/배지 공개는 기본 private, 공개는 분리된 동의/모더레이션 정책 필요.
- 권리 철회 시 기존 저장 도감에서 메타데이터 보존 가능 여부와 재생 불가 상태를 명확히 구분; 사용자에게 재생권이 존재하는 것으로 오인시키지 않음.
- 로그의 `user_id`, 청취/region/time 결합은 개인정보 위험. 집계·출력은 최소화, retention 삭제 정책 정의.

## Gate 체크리스트
실제 차트 데이터 법적 사용 승인 → 카탈로그/이미지/오디오 재생 권리 확인 → 지역별 정보/개인정보 정합성 검토 → 공급자 장애/삭제 대응 → 역사적 설명 편집 기준 승인. 미승인 상태는 demo fixture만 노출합니다.
