## 주요 사용자 시나리오
### U1. 1983년 도쿄
사용자는 1983-06-15/도쿄/당시 라디오 설정 → 처음 발매된 시점이 cutoff 이후인 작품은 제외 → 곡 선택 → 접근권한 확인 → 재생 → 마음에 드는 음반 저장. 1984년으로 이동하면 그 사이 발매된 곡이 새로 나타납니다.

### U2. 아티스트의 성장
아티스트를 선택 → 타임라인에서 정규 앨범 순서 탐색 → 2개 앨범 비교 → 참여 프로듀서 선택 → DigSession 분기 → 복귀 시 이전 위치 보존.

### U3. 2022년 겨울의 나
사용자 본인 청취/저장 이력을 기준으로 필터 → 후보 미리 듣기 → 발견 경로/메모 확인 → 다시 저장. 청취 이력 없으면 추측하지 않고 불완전한 데이터임을 표시.

### U4. 탐험 퀘스트
사용자가 선택적으로 퀘스트 시작 → 서버가 관계 방문/재생/저장 이벤트 확인 → 1회성 보상 확정 → 개인 프로필/도감에 표시. 반복재생/스크립트 조작으로 경험치 무한 지급 불가.

## 기능별 실패 상태
불명확한 지역, 후보 0건, 과거 데이터 부재, 외부 제공자 속도 제한, 권리 철회, 계정 오프라인, 아티스트/음반 중복 식별, 차트 라이선스 미승인, 지오코딩 부정확, 검색 인덱스 지연을 반드시 처리합니다.

## 비기능 수용 목표(초기 목표, 운영 측정 후 확정)
기본 목록 p95 서버 지연 <500ms(캐시된 질의), 그래프 첫 화면 최대 50노드/100간선, 시간 슬라이더 200ms 디바운스, 무한 요청 방지, 권리 재검사 100%, 프라이빗 정보 교차계정 노출 0, 오프라인에서는 이전 로드 데이터 read-only 명시. 수치는 성능 측정 후 ADR로 확정합니다.
