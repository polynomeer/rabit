# 제품 전략 · Music Atlas / Time Machine / Artist Journey

## 1. 문제
사용자는 곡을 우연히 발견하지만 이후 출처·제목·당시 경험을 잊습니다. 추천은 결과를 보여주지만 관계와 문화적 맥락을 충분히 설명하지 못합니다. 음악 세계는 지역·시대·아티스트·레이블·크레딧·장르·샘플링 등으로 연결되어 있습니다.

## 2. 비전
**Rabit의 DIG를 '설명 가능한 음악 탐험'으로 확장**합니다. 지도에서 시간축을 움직이며 음악을 발견하고, 선택 시점까지 존재한 작품만 재생하며, 아티스트 연대기를 따라 듣고, 탐험 경로를 기록·재방문하고, 선택적 미션과 도감으로 성취를 표현합니다.

### 제품 원칙
- **음악 먼저**: 탐험은 즐거움, 게임은 선택 사항. 차분한 재생(PLY-017)을 침범하지 않음.
- **미래 누출 방지**: `cutoff_at` 이후 발매 콘텐츠를 타임머신 후보에서 제외. 역사적 관점과 현대 해설 분리.
- **근거가 있는 연결**: verified / declared / inferred 표시, 출처 및 확신 수준 제공.
- **권한이 독립**: 탐험 지역/시점은 실제 라이선스 지역과 무관. 모든 재생은 기존 policy 평가.
- **진실한 진행도**: 우주의 '전체 음악'이 아니라 명확한 분모의 큐레이션 대상 대비 비율. 분모/버전 공개.
- **돌아올 수 있는 탐험**: trail·타임머신 세션·발견 맥락을 개인 Archive에 보관, 내보내기/삭제 지원.
- **대체 아닌 확장**: Listen, Archive, DIG, Atlas, Trust 통합. 기존 P0 범위 재정의 금지.

## 3. 대상 사용자와 Jobs-to-be-done
- 우연한 발견자: 모르는 시대의 음악을 부담 없이 들어보고 싶음 → Time Radio.
- 능동적 디거: 기준(연도, 국가, 장르, 차트)을 조합하고 연결을 추적 → Faceted Atlas + relation graph.
- 아티스트 팬: 앨범 변화와 협업 관계를 시간순으로 비교 → Artist Journey.
- 수집가: 어떤 영역을 탐험했는지 도감으로 확인 → bounded coverage, optional quests.
- 재발견 사용자: 제목 없이 시기·기분·발견 경로로 다시 찾기 → Memory timeline.

## 4. 핵심 제품 루프
지도/아티스트/과거의 나에서 시작 → 시간·지역·장르 범위 선택 → 재생 가능한 후보 샘플링 → 근거 있는 다음 연결 탐색 → 저장/트레일 → (선택적) 미션·컬렉션 → 재방문/재발견.

## 5. 성공 가설과 지표
- H1: 탐험 UI가 기존 DIG 리스트보다 유의미한 신규 아티스트 발견률을 높임. 7일 기준 탐색 세션당 '처음 감상하고 저장한 아티스트' 수, 실험군 비교.
- H2: 타임머신 맥락은 10분 이상 의미 있는 청취가 발생한 세션 비율을 높임. 자동 재생 시간만으로 성공 판단 금지.
- H3: Artist Journey가 앨범 단위의 완주와 재탐색률을 높임.
- H4: 재발견 흐름이 180일 이상 미청취 저장곡의 의미 있는 재청취를 증가시킴.
- Guardrails: 권리오류, skip률, 재생 실패, 탐색 피로, 앱 성능, 불필요한 알림/게임 압박, 개인정보 동의율.

## 6. 비목표
- 모든 시대/국가의 완전한 음악 목록 보장.
- Billboard 브랜드 또는 순위 데이터의 무허가 복제.
- 지도상의 임의 지역에 맞춘 라이선스 우회.
- 레벨이 음악 취향의 우월성/실력을 판단한다는 주장.
- 알고리즘만으로 역사적 사실이나 명반 여부를 단정.
- 임의 상용 외부 음원의 재생을 보장.
